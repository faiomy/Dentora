# Dentora - برنامج إدارة عيادة الأسنان

برنامج سطح مكتب لويندوز لإدارة عيادة أسنان كاملة: مرضى، مواعيد، مخطط أسنان،
إجراءات وأسعار، حسابات، طاقم عمل، معامل، ومصروفات - مع رسائل واتساب تلقائية
عبر تكامل n8n، ونظام ثيمات جاهز قابل للتخصيص.

## المميزات

- **المرضى**: إضافة، بحث، وعرض تفاصيل كل مريض - ملف كامل (صور شخصية، أشعة
  ومستندات، أرقام تليفون متعددة، ربط أفراد العائلة الواحدة، خصم خاص لكل مريض)
- **مخطط الأسنان (Odontogram)**: بمعيار FDI، حالات بزوغ وحضور كل سن، ملحوظات
  على أي سن بتاريخ واسم الطبيب، وتوليد تلقائي لخريطة الأسنان حسب عمر المريض
  (لبني/دائم) بناءً على الجدول الزمني العالمي للتسنين
- **المواعيد**: تقويم يومي بالساعات، مدة ولون لكل موعد، حالات (مؤكد/حضر/
  انتهى/ملغي/لم يحضر)، إجازات أسبوعية ثابتة وإجازات محددة، وساعات عمل العيادة
- **الإجراءات والأسعار**: أكتر من قائمة أسعار، أنواع فرعية لكل بند (زي زيركونيا/
  بورسلين للتيجان)، ألوان مميزة تظهر على شارت الأسنان، ونسبة عمولة لكل بند
- **سجل المعالجات والحسابات**: تسجيل كل معالجة تمت فعليًا بسعرها وخصمها
  والمبلغ المدفوع، مع حساب رصيد المريض وتقارير PDF بالعربي
- **طاقم العمل**: مستخدمين بصلاحيات (مدير/طبيب/سكرتارية) + فريق مساعد بدون
  حساب دخول، مع بيانات الرواتب والعمولات والمؤهل الزمني للزيادة السنوية
- **المصروفات**: تسجيل مصروفات العيادة بالتصنيف والمورد
- **حسابات العيادة**: إيرادات ومصروفات وأرباح أي فترة (يوم/شهر/سنة/فترة مخصصة)
  وملخص عمولات الأطباء
- **المعامل**: طلبات الشغل المرسلة للمعامل بحالات (مُرسل/تحت التنفيذ/مستلم/
  تم التسليم) وحساب مستحقات كل معمل
- **رسائل واتساب عبر n8n**: صفحة مخصصة لإرسال رسائل لأي رقم عبر webhook
  بتاع n8n، مع قوالب رسائل جاهزة (تأكيد حجز، تذكير موعد، شكر بعد الزيارة)
  بتتعبى تلقائيًا ببيانات المريض والموعد - وقاعدة البيانات جاهزة لتتبع
  رسائل التذكير التلقائية لما تتوصل بتشغيل n8n
- **الإعدادات**: اسم العيادة ولوجوها، ثيمات جاهزة كتيرة بمعاينة حية، خطوط
  عربية مختارة، أرقام تليفونات العيادة، ومصفوفة صلاحيات كاملة لكل دور
- **تسجيل الدخول**: حساب لكل مستخدم بكلمة مرور مشفّرة (PBKDF2)، مع خيار
  "تذكرني"، وتخصيص مظهر شخصي لكل مستخدم على نفس الجهاز

## طريقة التشغيل على جهازك (Windows)

### 1. تأكد إن بايثون مثبت
لو مش مثبت، حمّله من: https://www.python.org/downloads/
**مهم:** وانت بتثبته، اعمل تيك على خيار "Add Python to PATH"

### 2. افتح Command Prompt جوه مجلد البرنامج
```
cd path\to\dentora
```

### 3. ثبّت المكتبات المطلوبة (محتاج إنترنت)
```
pip install -r requirements.txt
```

### 4. شغّل البرنامج
```
python main.py
```

## إعداد رسائل واتساب (اختياري)

البرنامج بيبعت الرسائل عبر webhook بتاع n8n. عشان تفعّلها، حط متغيرات البيئة
دي قبل تشغيل البرنامج:

```
N8N_WEBHOOK_URL   (مطلوب) - اللينك الكامل للـ webhook
N8N_API_KEY       (اختياري) - بيتبعت كـ Bearer token لو حددته
```

الرسائل بتتبعت من غير ما توقف البرنامج، وبتتعمل 3 محاولات إرسال لو حصل
خطأ في الشبكة، وكل رسالة بتتسجل حالتها في جدول `n8n_message_log` في قاعدة
البيانات - والرسائل اللي فشلت بتحاول تتبعت تاني أول ما البرنامج يفتح.

> ملحوظة: الإرسال حاليًا يدوي من صفحة "تكامل n8n" جوه البرنامج. التشغيل
> التلقائي للتذكيرات محتاج ربط n8n الخارجي نفسه بالجدول الجاهز في قاعدة
> البيانات.

## فحص سريع من غير تشغيل الواجهة

```
python scripts/check.py
```

السكريبت ده بيعمل compile لكل ملفات بايثون، ويجرب إنشاء/ترقية قاعدة
البيانات على نسخة مؤقتة (من غير ما يلمس `clinic_data.db` الحقيقية)،
ويتأكد إن الثيمات والتكاملات سليمة. مفيد بعد أي تعديل في الكود.

## طريقة عمل ملف EXE قابل للتوزيع

بعد ما تثبت المكتبات، اعمل دبل كليك على ملف:
```
build_exe.bat
```
هيطلعلك الملف التنفيذي جوه مجلد `dist` باسم `ClinicApp.exe`، وده ملف واحد
تقدر تنقله لأي جهاز ويندوز ويشتغل من غير ما يحتاج بايثون مثبت عليه.

## بيانات الدخول الافتراضية

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**لازم تغيرها بعد أول تشغيل** (من صفحة الإعدادات > المستخدمون).

## ملاحظة عن قاعدة البيانات

البيانات كلها بتتخزن في ملف `clinic_data.db` جوه نفس مجلد البرنامج. لو
عايز تعمل نسخة احتياطية، انسخ الملف ده بس (مع ملفي `-wal` و `-shm` لو
موجودين). ممكن كمان تحط الملف على مجلد مشترك على الشبكة وتعدّل `DB_PATH`
في `database.py`.

## ملحوظات تقنية

- مجلد `ui/` وملف `qt_main.py` بقايا تجربة تحويل للواجهة لـ Qt اتجمدت -
  مش بيتشغلوا ولا بيتطوروا، والبرنامج الفعلي بيشتغل من `main.py`
- شكل البرنامج كله بيتحكم فيه `theme.py`: ثيمات جاهزة، تدرجات الهيدر،
  شكل أزرار الشريط العلوي (classic/glass/luxury)، ونمط الأيقونات
