# برنامج إدارة العيادة - النسخة التجريبية الأولى (MVP)

## اللي موجود في النسخة دي
- **المرضى**: إضافة، بحث، وعرض تفاصيل كل مريض
- **مخطط الأسنان (Odontogram)**: بمعيار FDI، اضغط على أي سن وحدد حالته (سليم/تسوس/محشو/تاج/عصب/مخلوع/زراعة)
- **المواعيد**: عرض حسب اليوم، إضافة موعد، تغيير حالته (مؤكد/حضر/انتهى/ملغي/لم يحضر)
- **الإعدادات**: اسم العيادة، رفع لوجو، اختيار اللون الأساسي للواجهة
- **شريط تنقل علوي** بدل السايدبار زي ما اتفقنا

## اللي لسه هيتضاف في المراحل الجاية
- المعامل (شغل رايح/راجع + حسابات المعامل)
- قائمة أسعار الخدمات العلاجية وربطها بخطة العلاج والفواتير
- المخزون والمستهلكات والموردين
- رسائل SMS/واتساب التلقائية (تذكير مواعيد + تهاني)
- نظام تسجيل الدخول والصلاحيات (مدير/طبيب/سكرتارية)
- تشغيل البرنامج على أكتر من جهاز في نفس الوقت (Server مركزي)

---

## طريقة التشغيل على جهازك (Windows)

### 1. تأكد إن بايثون مثبت
لو مش مثبت، حمّله من: https://www.python.org/downloads/
**مهم:** وانت بتثبته، اعمل تيك على خيار "Add Python to PATH"

### 2. افتح Command Prompt جوه مجلد البرنامج
```
cd path\to\clinic_app
```

### 3. ثبّت المكتبات المطلوبة (محتاج إنترنت)
```
pip install -r requirements.txt
```

### 4. شغّل البرنامج
```
python main.py
```

---

## طريقة عمل ملف EXE قابل للتوزيع

بعد ما تثبت المكتبات (خطوة 3 فوق)، اعمل دبل كليك على ملف:
```
build_exe.bat
```

هيطلعلك الملف التنفيذي جوه مجلد `dist` باسم `ClinicApp.exe`، وده ملف واحد تقدر تنقله لأي جهاز ويندوز ويشتغل من غير ما يحتاج بايثون مثبت عليه.
